# 材料说明

和题目文档的附录是同一份内容，这里是 JSON 版，方便程序直接读。全部虚构，时间一律是 UTC（ISO 8601）。

| 文件 | 内容 |
|---|---|
| `persona.json` | 柠柠的人设。只有文字，没有照片和声音样本。 |
| `user.json` | 对方，阿杰；也写了两人用的聊天软件。 |
| `chat.jsonl` | 两人的聊天记录，一行一条。她发照片或语音的位置，`kind` 是 `image` 或 `voice`，`trigger` 是时刻编号。 |
| `state.json` | 每个时刻她的状态：关系、心情、今天的安排、答应过的事、对方已经知道的事。 |
| `triggers.json` | T1–T6：时间、类型、要发什么；语音附了要说的话（`say`）。 |
| `sales/catalog.json` | 附加题：商品资料。 |
| `sales/chat.jsonl` | 附加题：客户发来的消息（葡语原文和中文），`to_send` 是要发的东西。 |
