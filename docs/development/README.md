# 开发与验收记录说明

本目录不是游戏代码，而是当前仍有参考价值的工程记录：

- `bug_log.md`：发现过的问题、原因、修复和回归测试。
- `change_log.md`：每批重要改动及验证结果。
- `decision_log.md`：为何选择离线优先、FileStorage、失败降级等设计。
- `traceability.md`：需求到实现、自动测试和人工证据的对应关系。
- `product_polish_qa_2026-10-17.md`：真实浏览器检查和产品评审修复。

内部 Agent 工作记录写入 Git 忽略的 `work/agent-ledger/`，不属于公开工程文档。可复用的
结论只保留在本目录的 Bug、变更、决策、追踪与 QA 记录中。
